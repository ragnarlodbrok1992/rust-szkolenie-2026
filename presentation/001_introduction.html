What is Rust?

A general-purpose, compiled systems programming language focused on safety, speed and concurrency.

YearMilestone
2006Started by Graydon Hoare as a personal project
2009Mozilla starts sponsoring the language
2015Rust 1.0: the stability promise begins
2021The Rust Foundation takes over stewardship
2025Rust 2024 edition released

Why Rust?

Memory safety without a garbage collector

The compiler checks how memory is used before the program runs. Details in chapter 3.

Performance

Compiles to native machine code. Speed comparable to C and C++.

Fearless concurrency

Data races are caught at compile time.

Helpful compiler

Error messages explain the problem and often suggest the fix.

Great tooling

One official tool builds, tests, formats, lints and documents your code.

Stability

Code written for Rust 1.0 still compiles with today's compiler.

Where is Rust used?

Operating systems

  • Linux kernel drivers
  • Windows kernel components
  • Android system services

Infrastructure

  • AWS Firecracker (serverless VMs)
  • Cloudflare network proxies

Applications

  • Firefox rendering engine parts
  • Discord backend services

Command-line tools

  • ripgrep, fd, bat

Web

  • Compiles to WebAssembly, which runs in the browser at near-native speed
  • Amazon Prime Video app, 1Password browser extension

The toolchain

rustupinstalls and updates Rust versions
→
cargobuild tool and package manager
→
rustcthe compiler
  • rustup installs the toolchain and keeps it up to date.
  • cargo is what you use every day. It calls rustc for you.
  • rustc turns .rs source files into an executable.

Installing Rust

Windows

Download and run rustup-init.exe from rustup.rs.

It needs the Visual Studio C++ Build Tools. The installer offers to set them up.

Linux and macOS 
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
Check the installation 
$ rustup --version
$ rustc --version
$ cargo --version
Update later 
$ rustup update

Release channels and editions

Channels

  • stable: a new release every 6 weeks. We use this one.
  • beta: the next stable release, for testing.
  • nightly: built every day, with experimental features.
$ rustup toolchain list

Editions

An edition is a set of language changes that you opt into per project.

2015 · 2018 · 2021 · 2024

Projects on different editions can still use each other as dependencies.

The ecosystem

Packages and docs

  • crates.io: the package registry. A package is called a crate.
  • docs.rs: documentation for every published crate.
  • rustup doc: the standard library docs, offline.

Learning

  • The Rust Programming Language ("the Book")
  • Rust by Example, Rustlings

Tools

  • rustfmt: formats code in the standard style.
  • clippy: a linter that suggests better code.
  • rust-analyzer: editor support, such as completion, go to definition and inline errors. Works with most editors.

Creating a project

New directory 
$ cargo new hello
Existing directory 
$ cargo init

By default both also create a Git repository and a .gitignore.

What we ran for this chapter 
$ cargo init --vcs none \
    --name introduction \
    001-introduction
  • --vcs none: the course repository already uses Git.
  • --name: a package name can't start with a digit.

Project layout

001-introduction/
├── Cargo.toml
├── Cargo.lock
├── src/
│   └── main.rs
└── target/
  • Cargo.toml: the project manifest. You edit it.
  • Cargo.lock: exact dependency versions. Cargo writes it.
  • src/main.rs: the entry point of a program.
  • target/: build output. Never commit it.

Cargo.toml

[package]
name = "introduction"
version = "0.1.0"
edition = "2024"

[dependencies]
  • [package]: information about this crate.
  • name: the crate name, also used for the executable.
  • edition: which Rust edition the code is written in.
  • [dependencies]: crates this project uses. Empty for now.

src/main.rs

fn main() {
    println!("Hello, world!");
}
  • fn main(): every program starts running here.
  • The function body sits between { and }.
  • println! prints a line. The ! means it's a macro, not a function. Macros come in chapter 4.
  • "Hello, world!" is a string literal.
  • The statement ends with ;.

The Cargo workflow

CommandWhat it does
cargo checkChecks that the code compiles without producing an executable. The fastest feedback.
cargo buildCompiles a debug build into target/debug/.
cargo runBuilds if needed, then runs the program.
cargo build --releaseOptimized build into target/release/. Slower to compile, faster to run.

Running the program

$ cargo run
   Compiling introduction v0.1.0 (...\001-introduction)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 1.82s
     Running `target\debug\introduction.exe`
Hello, world!
  • Compiling: Cargo calls rustc on the crate.
  • dev profile: a debug build. Unoptimized, but quick to compile.
  • Running: the path to the executable Cargo built.
  • The last line is the output of our program.
  • Run it again without changes and Cargo skips the compile step.

Behind the scenes: rustc

Cargo calls the compiler for you. You can also call it directly:

$ rustc src/main.rs
$ ./main
Hello, world!
  • Fine for a single file.
  • For real projects, use Cargo. It handles dependencies, build profiles and many files.

Formatting and linting

Format the code 
$ cargo fmt

Rewrites files in the official style. No more style debates.

Lint the code 
$ cargo clippy

Hundreds of checks for common mistakes and non-idiomatic code.

Both come with the default rustup installation.

Adding a dependency

Add the crate 
$ cargo add rand
Cargo.toml now contains 
[dependencies]
rand = "0.10.3"
  • cargo add finds the newest version on crates.io and writes it into Cargo.toml.
  • The next build downloads and compiles the crate.
  • Cargo.lock records the exact version used.
  • The version you get may be newer than the one shown here.

Using the dependency

fn main() {
    let dice_roll = rand::random_range(1..=6);
    println!("You rolled: {dice_roll}");
}
  • rand::random_range: the function random_range from the rand crate.
  • 1..=6 is a range from 1 to 6, inclusive.
  • let creates a variable, and {dice_roll} prints its value.

Variables, ranges and formatting are covered properly in chapters 2 and 4.

Reading compiler errors

fn main() {
    prinln!("Hello, world!");
}
error: cannot find macro `prinln` in this scope
 --> src/main.rs:2:5
  |
2 |     prinln!("Hello, world!");
  |     ^^^^^^ help: a macro with a similar name exists: `println`
  • Read errors from the top. The first one often causes the rest.
  • The arrow points at the file, line and column.
  • Look for the help: lines. They often contain the fix.

Summary

  • Rust is a compiled language that is both safe and fast.
  • rustup manages the toolchain, cargo drives the work, and rustc compiles.
  • A Cargo project has a Cargo.toml and its code in src/.
  • cargo check, cargo build and cargo run are the everyday commands.
  • Crates from crates.io are added with cargo add.
  • The compiler is your teacher. Read its messages.

Czym jest Rust?

Kompilowany język programowania systemowego ogólnego przeznaczenia, nastawiony na bezpieczeństwo, szybkość i współbieżność.

RokWydarzenie
2006Graydon Hoare zaczyna Rusta jako prywatny projekt
2009Mozilla zaczyna sponsorować język
2015Rust 1.0: początek gwarancji stabilności
2021Opiekę nad językiem przejmuje Rust Foundation
2025Wydanie edycji Rust 2024

Dlaczego Rust?

Bezpieczeństwo pamięci bez garbage collectora

Kompilator sprawdza użycie pamięci, zanim program zostanie uruchomiony. Szczegóły w rozdziale 3.

Wydajność

Kompilacja do natywnego kodu maszynowego. Szybkość porównywalna z C i C++.

Współbieżność bez obaw

Wyścigi danych są wykrywane podczas kompilacji.

Pomocny kompilator

Komunikaty błędów wyjaśniają problem i często podpowiadają poprawkę.

Świetne narzędzia

Jedno oficjalne narzędzie buduje, testuje, formatuje, analizuje i dokumentuje kod.

Stabilność

Kod napisany dla Rusta 1.0 nadal kompiluje się dzisiejszym kompilatorem.

Struktura projektu

001-introduction/
├── Cargo.toml
├── Cargo.lock
├── src/
│   └── main.rs

Cargo.toml

[package]

version = "0.1.0"
edition = "2024"

[dependencies]
  • [package]: informacje o tym crate'cie.
  • name: nazwa crate'a, używana też jako nazwa pliku wykonywalnego.
  • edition: edycja Rusta, w której napisano kod.
  • [dependencies]: crate'y, których używa projekt. Na razie pusto.

src/main.rs

fn main() {

}
  • fn main(): tu zaczyna się wykonanie każdego programu.
  • Ciało funkcji znajduje się między { a }.
  • println! wypisuje linię tekstu. ! oznacza, że to makro, a nie funkcja. Makra omówimy w rozdziale 4.
  • "Hello, world!" to literał napisowy.
  • Instrukcja kończy się znakiem ;.

Praca z Cargo

PolecenieCo robi
cargo checkSprawdza, czy kod się kompiluje, bez tworzenia pliku wykonywalnego. Najszybsza informacja zwrotna.
cargo buildKompiluje wersję debug do target/debug/.

Uruchamianie programu

$ cargo run
   Compiling introduction v0.1.0 (...\001-introduction)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 1.82s
     Running `target\debug\introduction.exe`
Hello, world!
  • Compiling: Cargo wywołuje rustc dla crate'a.
  • Profil dev: wersja debug. Niezoptymalizowana, ale szybko się kompiluje.

Za kulisami: rustc

Cargo wywołuje kompilator za nas. Można go też uruchomić bezpośrednio:

$ rustc src/main.rs
$ ./main
Hello, world!
  • Wystarcza dla pojedynczego pliku.
  • W prawdziwych projektach używaj Cargo. Zajmuje się zależnościami, profilami budowania i wieloma plikami.

Formatowanie i lintowanie

Formatowanie kodu

Lintowanie kodu

Dodawanie zależności

Dodanie crate'a 
$ cargo add rand
Cargo.toml zawiera teraz 
[dependencies]
rand = "0.10.3"
  • cargo add znajduje najnowszą wersję na crates.io i zapisuje ją w Cargo.toml.
  • Przy następnym budowaniu crate zostanie pobrany i skompilowany.
  • Cargo.lock zapisuje dokładną użytą wersję.
  • Pobrana wersja może być nowsza niż ta pokazana tutaj.

Użycie zależności

fn main() {
    let dice_roll = rand::random_range(1..=6);
    println!("You rolled: {dice_roll}");
}
  • rand::random_range: funkcja random_range z crate'a rand.
  • 1..=6 to zakres od 1 do 6 włącznie.
  • let tworzy zmienną, a {dice_roll} wypisuje jej wartość.

Zmienne, zakresy i formatowanie omówimy dokładnie w rozdziałach 2 i 4.

Czytanie błędów kompilatora

fn main() {
    prinln!("Hello, world!");
}
error: cannot find macro `prinln` in this scope
 --> src/main.rs:2:5
  |
2 |     prinln!("Hello, world!");
  |     ^^^^^^ help: a macro with a similar name exists: `println`
  • Czytaj błędy od góry. Pierwszy często powoduje kolejne.
  • Strzałka wskazuje plik, wiersz i kolumnę.
  • Szukaj linii help:. Często zawierają gotową poprawkę.

Podsumowanie

  • Rust to język kompilowany, który jest jednocześnie bezpieczny i szybki.
  • rustup zarządza narzędziami, cargo prowadzi pracę, a rustc kompiluje.
  • Projekt Cargo ma plik Cargo.toml, a kod w katalogu src/.
  • cargo check, cargo build i cargo run to polecenia na co dzień.
  • Crate'y z crates.io dodaje się poleceniem cargo add.
  • Kompilator jest twoim nauczycielem. Czytaj jego komunikaty.
